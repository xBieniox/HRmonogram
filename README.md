Aplikacja  „HRmonogram” jest narzędziem wspomagającym zarządzanie
zasobami ludzkimi oraz organizację czasu pracy w przedsiębiorstwach wielooddziałowych.
System umożliwia efektywne tworzenie i edycję grafików pracy, zarządzanie strukturą or
ganizacyjną firmy (obiekty, działy) oraz ewidencję pracowników i ich kontraktów. Aplika
cja została zaprojektowana z myślą o zautomatyzowaniu procesów HR, ułatwieniu pracy
menedżerom poprzez definiowanie preferencji zmianowych oraz zapewnieniu pracownikom
przejrzystego wglądu w ich harmonogram.
